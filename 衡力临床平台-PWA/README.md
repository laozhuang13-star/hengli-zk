# 衡力临床智库 PWA

本项目是 Base44 网页应用的轻量 PWA 启动外壳。

- 应用名称：衡力临床智库
- 目标网址：https://pro-hengli.base44.app/
- 图标：`icons/` 目录
- 缓存版本：`hengli-pwa-v3`

## 部署到 GitHub Pages

1. 在 GitHub 新建一个 **Public（公开）** 仓库。
2. 将本文件夹里的内容直接上传到仓库根目录，不要再套一层文件夹。
3. 打开仓库的 **Settings（设置）→ Pages（页面）**。
4. Source 选择 **Deploy from a branch**。
5. Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。
6. 等待 GitHub Pages 部署完成，使用页面显示的网址访问。

## 添加到手机桌面

- iPhone：用 Safari 打开 Pages 网址 → 分享 → 添加到主屏幕。
- Android：用 Chrome 打开 Pages 网址 → 浏览器菜单 → 安装应用/添加到主屏幕。

## 重要说明

这是网页应用的 PWA 外壳，不是原生 App。它只缓存启动外壳；Base44 中的登录、病例、知识库及其他功能仍需联网访问。
